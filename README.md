# Huzaifa Aamish, portfolio website

Senior SQA Engineer, AI QA and AI builder. Static site, no build step.

## Files
- index.html  the whole site (markup, styles, animations, chatbot UI)
- qa-kb.js    chatbot knowledge base, loaded only when the chat is opened
- profile.jpg add your photo with this exact name to show it in the header and hero

## Run locally
Open index.html in a browser, or `python3 -m http.server` in this folder and visit http://localhost:8000

## Deploy (GitHub Pages)
Settings > Pages > Source: Deploy from a branch > main / root. Site appears at https://huzaifa-aamish-sqa.github.io/Huzaifa-Profile/
