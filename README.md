# Huzaifa Aamish, portfolio website

Senior SQA Engineer, AI QA and AI builder. Static site, no build step.

## Files
- index.html            the whole site (markup, styles, animations, chatbot, case-study modal)
- qa-kb.js               chatbot knowledge base, loaded only when the chat is opened
- profile.jpg            profile photo shown in the hero
- favicon.ico / favicon-32.png / favicon-192.png / apple-touch-icon.png / favicon-512.png   site icon, all sizes
- og-image.png           the card shown when the site link is shared on WhatsApp, LinkedIn, etc.

## Sections
About, Expertise, Tools & stack, Services, How we work together (process), Selected work (case studies, click a card), Track record, Contact.

## Run locally
Open index.html in a browser, or `python3 -m http.server` in this folder and visit http://localhost:8000

## Deploy (GitHub Pages)
Settings > Pages > Source: Deploy from a branch > main / root. Site appears at https://huzaifa-aamish-sqa.github.io/Huzaifa-Profile/
